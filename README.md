# FTTH/PON Planner

Детерминированный конвейер проектирования FTTH/PON для новых населённых пунктов по спутниковым изображениям и GIS-данным.

Полная документация: [README_RU.md](README_RU.md)

## Конвейер

`изображение → здания → дороги → OLT → PON/FAT/муфты → трассировка → оптический бюджет → карта → спецификация`

Ключевые правила:

- один подтверждённый частный дом = один drop = один порт FAT;
- частные дома и МКД учитываются раздельно;
- FAT 1×8/1×16 по фактической локальной нагрузке;
- до 32 частных абонентов на PON по умолчанию;
- маршрутизация по дорожному графу;
- общий физический кабель не считается как сумма логических PON-путей;
- одна сварка соединяет два волокна, поэтому полностью свариваемый кабель 24F требует 24 сварочных места, а не 48;
- итоговая инженерная карта рисуется детерминированно из той же GIS-геометрии, что и спецификация.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python ftth_pon_planner.py init project.yaml
# заполнить project.yaml
python ftth_pon_planner.py run project.yaml
```

Выходные данные включают `network.geojson`, `network_map.png`, `drops.csv`, `fats.csv`, `muftas.csv`, `pons.csv`, `feeder_cable_by_capacity.csv` и `qa_report.json`.

Перед строительством автоматические слои зданий, дорог и расчетную точку OLT необходимо проверить по GIS/полевым данным.
